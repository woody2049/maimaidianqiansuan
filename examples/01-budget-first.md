# 示例 1：预算够、不限营养，想吃得划算

**用户说**：「预算 40，麦当劳想吃麦辣鸡腿堡加中薯条，怎么点最省？」

## 输入

```json
{
  "budget": 40,
  "nutrition": "any",
  "pickup": "pickup",
  "want": ["spicy", "friesM"],
  "avoid": [],
  "coupon": "prefer",
  "store": { "delta": 0, "soldout": [] },
  "weekday": 1
}
```

## 命令

```bash
python3 scripts/meal_planner.py --budget 40 --nutrition any --pickup pickup \
    --want spicy,friesM --coupon prefer --weekday 1
```

## 输出

```text
## 条件
- 预算：¥40｜营养参考：不限｜取餐方式：到店自取
- 必吃：麦辣鸡腿堡、中薯条｜忌口：无｜券偏好：优先用券
- 门店：差价 +0.0｜停售：无｜可选 30 件

## 筛选过程
穷举 60 种组合 → 预算内 16 种 → 同时达到营养参考 16 种（候选池）

## 预算优先
- 总价 ¥47｜优惠 −¥11.6｜**实际应付 ¥35.4**
- 用券：随心配 1+1（单张最优，不叠加）
- 餐品：麦辣鸡腿堡 ¥21.5、中薯条 ¥12.5、柠檬茶 ¥13
- 营养：1000 千卡 / 蛋白质 28g / 脂肪 42g / 钠 1165mg
- 该组候选 5 个（换一组方案可翻页）

## 营养参考优先
- 总价 ¥43.5｜优惠 −¥8.1｜**实际应付 ¥35.4**
- 用券：随心配 1+1（单张最优，不叠加）
- 餐品：麦辣鸡腿堡 ¥21.5、中薯条 ¥12.5、零度可乐（中） ¥9.5
- 营养：860 千卡 / 蛋白质 28g / 脂肪 42g / 钠 1190mg
- 该组候选 5 个（换一组方案可翻页）

## 口味优先
- 总价 ¥48｜优惠 −¥8｜**实际应付 ¥40**
- 用券：满 45 减 8（单张最优，不叠加）
- 餐品：麦辣鸡腿堡 ¥21.5、中薯条 ¥12.5、纯牛奶 ¥8、圆筒冰淇淋 ¥6
- 营养：1140 千卡 / 蛋白质 39g / 脂肪 54g / 钠 1310mg
- 该组候选 5 个（换一组方案可翻页）
```

## 规则怎么落地的

- **必吃锁定主餐 + 小食**，所以三组都从「麦辣鸡腿堡 + 中薯条」起步，只在饮品/甜品上做取舍——这就是必吃项占类目的效果，而不是简单地在结果里加两道菜。
- **随心配 1+1** 把「中薯条 + 柠檬茶」（12.5 + 13 = 25.5）改价到 13.9，省 11.6，是三张券里最优的一张；满 45 减 8 只有总价够 45 才划算。
- **营养优先组**用零度可乐替换柠檬茶：少 140 千卡、总价降 3.5，优惠随之从 11.6 降到 8.1，**应付仍是 35.4**。同价不同热量，这是这一组存在的意义。
- **口味优先组**为了「吃得满足」多加圆筒冰淇淋（第 4 件，仍在 2–4 件限制内），凑到 48 元触发满 45 减 8，应付刚好压在预算线 40。

## 读这一例该注意

三组不是「三个价格档」。预算优先和营养优先实付完全一样，差别只有 140 千卡——所以「最省」和「最贴合目标」在这一单里可以同时成立。
